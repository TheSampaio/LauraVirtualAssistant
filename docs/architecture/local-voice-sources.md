# Local voice source companion

The optional native voice worker uses sherpa-onnx 1.13.8, NuGet repository commit `dc5583f49917e4c95f6e7d862bb378e4ed5e9076`. Its native phonemizer links the GPL-3.0 eSpeak-NG fork at `ed530aa113046142eb5115cf2fc9157854d0ffe1`; the Apache package label does not replace dependency license terms. The separate worker communicates through stdin/stdout and has no microphone, network client or native tool executor. Laura's managed source retains its MIT license. Applicable GPL rights and disclaimers accompany the native combined component.

Before distributing native voice binaries, prepare the matching source companion with `pwsh -NoProfile -File Build/Prepare-VoiceSources.ps1 -Download`. This explicitly downloads sources, never model weights. Later release builds verify these already prepared source archives without network access. `VoiceSources/` accompanies the binary package; this is actual source delivery, not a promise to provide it later. Do not distribute a binary-only subset.

`Upstream/sherpa-onnx-dc5583f4.zip` contains the native library, managed binding, CMake files and original build workflows. Exact pinned dependency sources and their licenses accompany it. Extract each dependency into a build directory and provide the CMake `FETCHCONTENT_SOURCE_DIR_<NAME>` overrides matching its `FetchContent_Declare` name, or place archives at the local locations documented in the corresponding upstream CMake files. Configure a Windows x64 Release shared-library build with MSVC and CMake, following the included upstream NuGet workflow; retain its C API and TTS support and CPU ONNX Runtime 1.28.2. No secret signing keys are needed to rebuild or replace the worker. ONNX Runtime has its own upstream CMake build instructions inside its source archive. Build the managed host with `dotnet publish Laura.VoiceWorker/Laura.VoiceWorker.csproj -c Release -r win-x64 --self-contained true`. The source companion contains its Core reference, lock files and SDK pin. Native replacement requires an ABI-compatible sherpa C API; binaries are not required to be byte-identical to the upstream NuGet release.

The source companion is independently hashed in `source-manifest.json` and the complete release package manifest. An unmodified upstream release remains distinguishable from Laura's worker implementation. Model weights are downloaded separately only after explicit review, with their own source revisions, checksums and licenses. No quality or licensing claim for a different imported model follows from this pack's validation.
