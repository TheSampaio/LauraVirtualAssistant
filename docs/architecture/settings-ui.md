# Native settings workspace

Settings and Brain use the same `Theme.PageHeading`, compact SVG `BackButton`, brand lockup, page insets and translated back description. Action buttons, selected tabs and pointer/keyboard states come from shared Theme factories rather than page-local styling. The primary action fill is `#CC1939`, preserving red identity while improving contrast with the existing light text; luminous markers retain the brighter accent. Dense toolbars may use icon-only variants with the same 44-pixel target and tooltip. Layout differences reflect each workspace's content, while Brain's unsaved-document guard and the 300 ms navigation transition remain intact.

Settings retain the existing MAUI controls, settings service, Gemini validation and protected credential store. Four persistent tab views preserve drafts while switching tabs. The save action stays outside the scroll viewport. The workspace is centered with a maximum width of 980 device-independent pixels; below 900 pixels, tabs form two rows and wide fields move below their labels. Scroll content reserves a separate right gutter so native scrollbars cannot cover values or controls. Navigation keeps the shared 300 ms transition and cached-page reuse.

Connection status reports whether a credential is stored, without claiming an active Gemini connection. The stored secret remains outside the editable entry: its placeholder is a fixed mask. Reveal applies only to the entered draft; reopening or clearing a saved draft restores masking. Explicit copy actions can copy a credential or application path to the clipboard. Saving still validates a replacement before persisting it, preserves the verified credential if the draft changes during validation, and uses DPAPI. Voice preview remains an explicit user action.

Applications use the actual Windows catalog in a finite-height virtualized CollectionView, with native recycled rows, SVG icons, path copying, an actual result count and 180 ms debounced name/path filtering. The previous 60-row display cap is removed without eagerly constructing the whole inventory. Discovery stays in the existing background service. This page does not automatically launch applications. Native switches remove WinUI's unused caption width while retaining keyboard activation and a minimum 44-pixel-high hit target.

All added labels and descriptions have EN/PT catalog parity. Clap wake guidance reflects the existing behavior: two claps acknowledge and start listening; the startup greeting supplies the briefing. Lucide assets are bundled with the existing license, with no additional UI package or runtime asset download.

Verification uses the isolated native UI smoke runner: all four tabs in EN/PT, 1440×900 and minimum 720×600 windows, draft preservation, virtualized inventory realization, scroll access to voice/personality controls, and repeated cached-page navigation. It never opens the physical microphone, copies a credential or calls Gemini. The credential validation algorithm remains unchanged; the optional cloud credential verification requires its separate explicit smoke flag.
