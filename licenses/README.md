# License bundle

These are unmodified upstream license and third-party attribution texts for the distributed managed/native dependencies. `dependency-inventory.json` records every resolved application NuGet dependency, license declaration, package hash, repository and commit where supplied. It includes runtime packages for other architectures pulled transitively by upstream packages; the supported release is Windows x64 only. NuGet lock files record the dependency graph. `upstream-sources.json` identifies separately retrieved official source texts; other files were extracted directly from the corresponding NuGet archives.

The self-contained release resolves .NET/WindowsDesktop 9.0.20. Native llama.cpp is pinned by LLamaSharp 0.27.0 to `3f7c29d318e317b63f54c558bc69803963d7d88c`. Whisper.net 1.9.1 pins whisper.cpp to `f24588a272ae8e23280d9c220536437164e6ed28`. Sherpa 1.13.4's Windows x64 build declares ONNX Runtime 1.27.0. SQLite itself is public domain; its wrapper is Apache-2.0. SQLite's canonical copyright statement is https://www.sqlite.org/copyright.html.

Microsoft packages are covered by their MIT license and accompanying third-party notices; NAudio's subpackages share its license. System.Linq.Async and System.Interactive.Async come from the MIT-licensed .NET Reactive project. Model licenses are included for attribution, but model weights are not part of the application package. Reference project source/assets are not redistributed. See `THIRD_PARTY_NOTICES.md` for their credited authors and integration decisions.

Microsoft CRT/OpenMP binaries are separately licensed proprietary redistributable components, not MIT. See the included official runtime/Visual Studio terms and distributable list. The signed Release-channel files are pinned in `vc-runtime-inventory.json`. DLLs are copied only from the licensed redistributable folder at publish time and are not committed. Early preload keeps Windows speech from selecting a global C++ runtime before the native engines start. Security updates require deliberately updating this manifest and republishing Laura.
